### 启动组（src/launchGroups.ts 纯函数 + extension/treeProvider 增量）
- 配置 `npm-run.groups`（object：组名→ref 数组），UI 回写 ConfigurationTarget.Workspace，手写共存，onDidChangeConfiguration 热刷新
- **ref 格式 `项目:脚本`，分隔符必须 indexOf（第一个冒号）**——我最初写成 lastIndexOf 还配了错误注释，测试当场抓住：`apps/web:dev:watch` 被切成 `apps/web:dev`+`watch`。语义是脚本名可含冒号、路径/name 不含，所以取第一个
- 解析优先级：相对路径精确匹配（normPath：斜杠统一+去尾+toLowerCase，Windows 友好）→ name 兜底（仅唯一命中）→ script 必须在声明中；失败保留 ref 显示 ⚠ 不消失
- `relativeDirOf(dir, folders)`（launchGroups 导出，folders 参数化可单测）：单根=相对路径（根项目 '.'）；**多根=「folder名/子路径」**（folder 名不含冒号，防止破坏 ref 分隔语义；绝对路径含 `C:` 盘符冒号是同一陷阱）
- 树：组节点（rocket，n 个脚本 · n 个未解析，tooltip 列成员）平铺树顶；成员行显示「name · script」+ 运行中状态（sync~spin）；未解析成员 description 提示
