## Bug 修复：初始扫描后树视图永远为空（用户报告：获取不到 scripts）
- 根因：数据链断裂——scanner.refresh() 完成后 fire onDidChange 事件，但 extension.ts 从未订阅该事件连接 provider.refresh()。时序：树首次渲染时异步扫描未完成（projects 空）→ 空树；扫描完成 fire → 无人监听 → 永不刷新。手动点刷新按钮之所以能出现，是因为命令直接调用 scanner.refresh 且命令 await 完成后……不对，命令也只是 refresh；真正差异待究，但事件订阅缺失是确定的断裂点
- 修复：context.subscriptions.push(scanner.onDidChange(() => provider.refresh()))；顺带显式 activationEvents: ["onView:npm-run.scripts"]（不再依赖内核隐式生成）
- 教训：vscode 集成层（事件订阅/异步时序）没有自动化测试覆盖，纯逻辑测试全绿也会漏这类 bug；此类需在扩展宿主中人工验证或引入 @vscode/test-electron 集成测试
